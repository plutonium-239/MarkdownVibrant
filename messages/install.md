An all-encompassing, high-contrast, feature-packed Markdown plugin for Sublime Text 4.

Thanks for installing! Highlights:

- A vibrant color scheme applied automatically to Markdown, MultiMarkdown, and Markdown Extended files.
- A native side-by-side HTML live preview (`Cmd+Option+M` / `Ctrl+Alt+M`) that re-renders as you type.
- GitHub-flavored Markdown in the preview: tables, task lists, strikethrough, autolinks, footnotes, and `[!NOTE]`-style callouts.
- A table formatter (`Cmd+Alt+Shift+T` / `Ctrl+Alt+Shift+T`), also run automatically on save.
- A TOC generator (`Cmd+Option+G` / `Ctrl+Alt+G`) and task checkbox toggling (`Cmd+Option+C` / `Ctrl+Alt+C`).

See the [README](https://github.com/plutonium-239/MarkdownVibrant#markdownvibrant-for-sublime-text-4) for all settings (table formatting, preview behavior, callouts).
